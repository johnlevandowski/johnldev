You've reached [John Levandowski](https://johnlevandowski.com/)'s personal home network domain.

Behind the scenes, this domain serves as the gateway for my home lab setup. I manage my infrastructure using Podman quadlets and pods. Feel free to check out my setups on [GitHub](https://github.com/johnlevandowski/podman).

Some of the container images I build and run locally:
- [Unbound](https://github.com/johnlevandowski/unbound/pkgs/container/unbound) : A recursive DNS resolver working alongside Pi-hole.
- [Caddy + Cloudflare](https://github.com/johnlevandowski/caddy-cloudflare/pkgs/container/caddy-cloudflare): A reverse proxy for internal services that automates HTTPS certificates using Cloudflare DNS.
